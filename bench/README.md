## Record per run
Task/data revision, configuration/model/tool versions, seed, outcome metric, valid completed experiments, wall time, human time if measured, cost, citation outcomes, failures, and raw artifact path.

## Reporting
Report denominators and uncertainty. Do not infer discovery quality from throughput alone.
