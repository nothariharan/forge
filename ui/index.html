On your side, under your control

FORGE is built on Omnigent. Omnigent spawns and governs the agents; FORGE adds the scientific workflow and the record.

Omnigent orchestrates

Spawns the director and seven specialists, holds their sessions, and enforces policy in the engine itself: a dispatch and experiment budget (P2) and a tool allowlist that applies to every sub-agent (P5).

FORGE validates

Every handoff is checked against the event schema before it is recorded. A malformed one is rejected and logged with its raw input, and the engine blocks the next dispatch until it is fixed.

Humans decide

The lab and the command line only read the ledger and send decisions back. Experiments wait on a human approval (P6), and agents can never write one themselves.

Meet the agents

Eight agents and one human ran the live loop. The rest are on call: Omnigent summons them when a different domain needs them, and the lab gives each its own character.

Run it yourself

The website replays a recorded run. To run FORGE on your own question, you need Omnigent and a Claude subscription or API key on your machine (macOS or Linux, Python 3.12, Node 22, tmux).

  1. Install Omnigent and connect Claude
    curl -fsSL https://omnigent.ai/install.sh | sh && omni setup

    In omni setup, pick Claude (subscription or API key) as the default.

  2. Get the code
    git clone https://github.com/nothariharan/forge && cd forge && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt -r requirements-science.txt
  3. Start the lab (terminal 1)
    .venv/bin/python ui/live_server.py --port 8777 --db results/ledger.db
  4. Ask your question (terminal 2, from the repo root)
    FORGE_LEDGER_DB=$PWD/results/ledger.db omni run omnigent/forge --no-session -p "Run id my-run. Your research question here." </dev/null
  5. Watch it and approve the experiment
    open http://localhost:8777/ui/lab.html?run=my-run

    When Safety opens a gate, a red banner appears: press Approve. Or from a terminal: .venv/bin/python -m cli.approve my-run G1

Experiments only run through approved tools. Today that is the preregistered TESS T1 shift check; to add your own, list it in tools/forge_gate.py (APPROVED_TOOLS). Every run is checked with .venv/bin/python -m cli.verify my-run.
